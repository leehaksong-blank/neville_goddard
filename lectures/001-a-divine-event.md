# 001. A Divine Event (1969-12-08)

---

### Sentence 01 (Paragraph 01)
**Christmas is the proclamation of a divine event to which all creation aspires.**

> 크리스마스는 모든 피조물이 열망하는 신적 사건을 선포하는 날입니다.

* **[핵심 어휘 및 숙어]**
  * **proclamation** : 선언, 선포
  * **divine** : 신성한, 신의
  * **creation** : (집합적) 모든 피조물, 창조 세계
  * **aspire to** : ~을 열망하다, 염원하다
* **[구문 및 문법 해설]**
  * **전치사 + 관계대명사 (to which)** — 선행사 a divine event를 수식합니다. 본래 all creation aspires to the event 구조에서 전치사 to가 관계대명사 which 앞으로 이동하여 결합했습니다.

---

### Sentence 02 (Paragraph 01)
**It is an event which puts an entirely different light upon human life, for it proclaims that man has been saved.**

> 이 사건은 인간의 삶을 완전히 다른 시각으로 보게 만드는데, 왜냐하면 인간이 이미 구원받았음을 선포하기 때문입니다.

* **[핵심 어휘 및 숙어]**
  * **put ~ upon a different light** : ~을 새로운 각도/시각에서 보게 하다
  * **entirely** : 전적으로, 완전히
  * **for** : [접속사] 왜냐하면 ~이므로 (앞 절의 근거 제시)
  * **man** : [무관사 단수] 인류, 인간 일반
* **[구문 및 문법 해설]**
  * **주격 관계대명사 (which)** — 선행사 an event를 수식하는 형용사절을 이끕니다.
  * **현재완료 수동태 (has been saved)** — 구원이 미래의 조건부 사건이 아니라 이미 완료되어 현재까지 확정된 상태임을 나타냅니다.
